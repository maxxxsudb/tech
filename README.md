# Tech AI Assistant

Текущая версия: **0.5.3**.

Компактный frontend-only app plugin для Grafana 13.0.2. Сборочные зависимости и отдельный backend-контейнер не нужны: ключ хранит Grafana в `secureJsonData`, запросы идут через штатный plugin proxy.

## Установка

Скопировать содержимое `plugin/` в каталог плагинов как `tech-ai-assistant-app` и добавить:

```ini
[plugins]
allow_loading_unsigned_plugins = tech-ai-assistant-app
```

Плагин автоматически учитывает `root_url`/`serve_from_sub_path` через `config.appSubUrl`.

Настройка: **Administration → Plugins and data → Plugins → Tech AI Assistant → Configuration**.

- `Шаблон провайдера`: заполняет поля для Ollama, LM Studio, vLLM, llama.cpp server, OpenAI, Gemini или Groq.
- `API URL`: адрес OpenAI-compatible сервиса так, как его видит сервер Grafana (например `http://ollama:11434`).
- `Chat completions path`: обычно `/v1/chat/completions`; `Models path`: обычно `/v1/models`.
- `Model`: имя модели; кнопка **Загрузить список моделей** подставляет варианты из `/v1/models`.
- **Проверить подключение** отправляет короткий запрос с сохранёнными настройками и показывает ответ или понятную ошибку.
- `Окно контекста модели`: размер окна в токенах. Плагин сжимает контекст и историю под этот лимит. Для Ollama задайте такое же значение через `OLLAMA_CONTEXT_LENGTH` или `num_ctx`, иначе Ollama молча отбросит начало промпта вместе с контекстом дашборда.
- `Потоковый вывод (stream)`: ответ появляется по мере генерации, есть кнопка **Стоп**. Если provider не поддерживает streaming, плагин автоматически повторяет запрос в обычном режиме и до конца сессии браузера больше не запрашивает stream у этой модели (в заголовке чата появляется «без stream»; сохранение настроек сбрасывает флаг).
- `Как модель выполняет дополнительные запросы`: по умолчанию текстовый протокол, работающий с любой моделью без поддержки tools; можно включить native tools или native с откатом на текст.
- `Reasoning effort`: необязательный уровень рассуждения, например `low` для Gemini.
- `Max output tokens`: ограничение длины ответа; `0` использует значение провайдера.
- `API key`: хранится зашифрованным в Grafana. Для внутреннего сервиса ключ можно оставить пустым — Authorization header отправляться не будет.
- `Authorization header`: отключить для внутреннего сервиса без авторизации.

### Groq Free

Выберите `Provider: Groq Free`, сохраните отдельный Groq API key и модель `qwen/qwen3.8-27b`. Gemini/custom-профиль и его ключ при переключении сохраняются.

Контекст содержит текущий URL, UID и JSON дашборда (включая панели в свёрнутых rows), time range, текущие значения переменных, запросы панелей и ограниченную выборку фактических результатов/ошибок. Перед выполнением запросов переменные дашборда подставляются так же, как это делает datasource. Если контекст не помещается в окно модели, сначала отбрасываются второстепенные поля (fieldConfig других панелей, лишние строки данных), а под полем ввода видно, сколько токенов ушло и что было сжато.

Диалог хранится в `sessionStorage` отдельно для каждого дашборда и панели и переживает перезагрузку страницы; **Новый диалог** очищает его. Ответы рендерятся как Markdown, у блоков кода есть кнопки **Копировать** и **Открыть в Explore**, размышления reasoning-моделей (`<think>`) свёрнуты.

- На любом дашборде: оранжевая кнопка **AI** справа снизу открывает drawer поверх дашборда.
- В Command Palette (`Ctrl+K`): **Открыть Tech AI Assistant**.
- В Explore: **Add → Спросить AI**.
- Для контекста конкретной панели: `⋮` у панели → **Extensions** → **Спросить AI**.

В Configuration выбирается способ запуска: кнопка, Command Palette или оба. Там же задаются максимальное число строк результата, allowlist datasource UID и минимальная роль.

Быстрые действия:

- объяснить, исправить или оптимизировать запрос;
- расследовать проблему с дополнительными read-only запросами к Loki, Prometheus и Tempo (список типов настраивается). Запросы AI ограничены: диапазон не длиннее `aiQueryMaxRangeHours` (24 ч по умолчанию, отсчёт от конца диапазона дашборда), таймаут `aiQueryTimeoutSeconds` (30 с, действует и на запросы панелей), не больше `aiQueryMaxPerTurn` (6) запросов за ответ, не больше 200 строк Loki и 20 трейсов Tempo; «Стоп» прерывает и запросы к datasource; выполненные запросы показываются карточками со ссылкой в Explore. Галка **Разрешить AI выполнять запросы** включает это и для обычных вопросов;
- показать diff предложенного `dashboard-json`, скопировать или применить его после подтверждения.

При применении плагин повторно загружает текущий дашборд, проверяет права, существование панели (в том числе внутри rows) и запрещает незапрошенную смену datasource. Сохранение идёт с проверкой версии: если дашборд успели изменить, правки не затираются. Токены, cookies и поля с секретами вычищаются из передаваемого контекста. Полный серверный аудит текстов запросов требует отдельного backend-компонента.

Для медленных моделей задайте Grafana `GF_DATAPROXY_TIMEOUT=120`: стриминг показывает прогресс, но таймаут прокси всё равно действует.

«Минимальная роль» проверяется в браузере; маршруты plugin proxy доступны с ролью Viewer. Для жёсткого ограничения поднимите `reqRole` в `plugin.json`.

## Тесты

```bash
node --test test/unit.test.js
```

Unit-тесты покрывают разбор стрима, текстовый протокол запросов, сжатие контекста, rows и санитизацию без Grafana и браузера. E2E-скрипты `test/verify-*.js` работают против запущенной Grafana.

Качество модели и промпта проверяется набором эталонных вопросов: `node evals/run.js`, см. [evals/README.md](evals/README.md).

## Снимок дашборда

В AI-панели включите `Сделать и отправить снимок дашборда для анализа`. Браузер попросит выбрать текущую вкладку Grafana, после чего плагин приложит один JPEG-кадр к запросу и сразу остановит захват. Галочка по умолчанию выключена.

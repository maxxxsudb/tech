# Эталонные вопросы

16 типовых задач, на которых видно, справляется ли модель и промпт с работой ассистента: объяснить панель,
починить PromQL, написать LogQL, предложить алерт, честно сказать «данных нет», провести расследование
через текстовый протокол `grafana-query`, уложиться в маленькое окно контекста. Кейсы и проверки лежат в
[`cases.js`](cases.js), прогон в [`run.js`](run.js).

Прогон идёт через тот же код, что работает в плагине (`plugin/module.js`): сборка system prompt, сжатие
контекста под окно, стриминг с откатом, цикл дополнительных запросов. Запросы к datasource не выполняются —
кейсы отвечают на них заготовленными данными, поэтому результат не зависит от состояния стенда.

## Запуск

Нужен только Node 18+.

Напрямую к модели (с машины или контейнера, откуда она доступна):

```bash
LLM_URL=http://ollama:11434 LLM_MODEL=qwen3:8b CONTEXT_TOKENS=8192 node evals/run.js
```

Через Grafana, с сохранёнными настройками плагина и его plugin proxy:

```bash
GRAFANA_URL=http://tech-ai-grafana-test:3000/crf/dashboard GRAFANA_USER=admin GRAFANA_PASSWORD=admin node evals/run.js
```

| Переменная | Значение |
|---|---|
| `LLM_URL`, `LLM_PATH` | адрес и путь OpenAI-compatible API (`/v1/chat/completions` по умолчанию) |
| `LLM_MODEL`, `LLM_API_KEY` | модель и ключ (ключ можно не задавать для локальной модели) |
| `CONTEXT_TOKENS` | окно контекста, как в настройке плагина (8192 по умолчанию) |
| `MAX_TOKENS`, `REASONING_EFFORT` | как в настройках плагина |
| `TOOLS_MODE` | `text` (по умолчанию), `auto` или `native` |
| `STREAM=0` | отключить стриминг |
| `SYSTEM_PROMPT_FILE` | файл с альтернативным system prompt для сравнения |
| `CASE_TIMEOUT_S` | таймаут одного кейса, 300 с по умолчанию |

Флаги: `--case fix-syntax,investigate` — только выбранные кейсы, `--repeat 3` — несколько прогонов
(у локальных моделей ответы плавают), `--out file.json` — куда сохранить отчёт.

## Результат

В консоли строка на кейс: прошёл ли он, сколько проверок прошло, время ответа и время до первого токена,
какие проверки не прошли. В конце — итог по категориям. Полный отчёт с ответами модели сохраняется в
`evals/results/<дата>-<модель>.json` (каталог в `.gitignore`).

Как пользоваться: прогоните текущую модель и сохраните отчёт как точку отсчёта. После смены модели,
квантизации, system prompt или окна контекста прогоните снова с `--repeat 3` и сравните число кейсов
и проверок. Код выхода 1, если хотя бы один кейс не прошёл.

Чтобы добавить кейс, допишите объект в `cases.js`: `prompt`, `context` (через `dashboard({...})`),
`checks`, а для расследований `queries: true` и `respond(args)` с ответом datasource.

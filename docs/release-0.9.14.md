# 0.9.14 — точечная чистка интерфейса

Обычный экран остаётся прежним: четыре стартовых действия, подробности свёрнуты, поле вопроса закреплено снизу. Новых разделов и настроек нет.

- Подсказка вопроса соответствует текущему контексту: SQL, PromQL, Loki, конкретный алерт или обзор алертов. На странице Alerting приветствие также говорит об алерте.
- Метка «Структура» заменяет двусмысленное «Без данных», которое можно было принять за проблему datasource. Подсказка поясняет, что в контексте есть запросы/настройки, а выборка datasource не добавлена. Режимы передачи данных и выполнение запросов не менялись.
- Если запись silence осталась неопределённой, разделы раскрываются до сверки, а статус прокручивается в видимую область карточки. На этом этапе показаны результат и кнопка сверки; заблокированная форма скрыта. После сверки фактический silence остаётся открыт для проверки, preview/confirmation по-прежнему сброшены. Без pending подробности остаются свёрнутыми.

Визуальный прогон сравнивает исходный module из тега v0.9.13, source 0.9.14 и точные production bytes protected. Снимки сделаны в настоящей Grafana 13.2.2 при 1400×1000 и 390×844, в светлой и тёмной темах. Для UI-fixture подменены модель/настройки, alert-read ответы и datasource query; реальные SQL и работа этих API этим визуальным прогоном не подтверждаются. Без отправки вопроса проверяется ноль model/datasource query/изменяющих alert API запросов. Отдельный live alerting-прогон проверяет настоящие PostgreSQL/API и сверку silence на production bytes.

Результаты и SHA-256: [протокол](implementation-blocks.md). Изображения/OCR/MIME/transport, SQL guard, подтверждения записи и backend не менялись.

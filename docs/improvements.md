# Улучшения Tech AI Assistant

Полный разбор версии 0.4.0 с обоснованием: [review-0.4.0.md](review-0.4.0.md).

## Сделано в 0.5.0

| Пункт разбора | Что сделано |
|---|---|
| 1. Drawer не помнил диалог | Кнопка AI монтирует тот же React-чат, что sidebar и модалка панели. История в `sessionStorage` по дашборду/панели, кнопка «Новый диалог», Esc закрывает drawer. Удалено ~180 строк дублирующего DOM-кода. |
| 2. Markdown и код | Ответы рендерятся через `renderMarkdown` Grafana (с санитизацией). У блоков кода кнопки «Копировать» и «Открыть в Explore» для PromQL/LogQL/TraceQL. |
| 3. Стриминг | `stream: true` через `fetch` к plugin proxy, разбор SSE, кнопка «Стоп» (частичный ответ сохраняется), `<think>` и `reasoning_content` сворачиваются. Если провайдер ответил обычным JSON, он тоже принимается. |
| 4. Контекст | Переменные подставляются через `interpolateVariablesInQueries` datasource (запасной вариант `templateSrv.replace`), значения переменных берутся из состояния дашборда, время по умолчанию из дашборда, панели свёрнутых rows видны и применяются. |
| 5. Бюджет контекста | Настройка «Окно контекста модели». Контекст сжимается по приоритетам без разрезания JSON, старые сообщения истории отбрасываются парами, под полем ввода видно «≈N ток. из M» и что сжато. |
| 6. Провайдеры | Шаблоны Ollama / LM Studio / vLLM / llama.cpp / OpenAI / Gemini / Groq, «Проверить подключение», «Загрузить список моделей» (`/v1/models`, новые маршруты `models`, `models-auth`, `groq-models`). |
| 7. Запросы AI без tools | По умолчанию текстовый протокол `grafana-query`, работающий с любой моделью. Режимы «native tools» и «native с откатом на текст». Последний раунд всегда даёт итоговый ответ. Выполненные запросы видны карточками со ссылкой в Explore. Галка «Разрешить AI выполнять запросы» для обычных вопросов. Типы datasource настраиваются. |
| 8. Применение | `overwrite: false` с версией дашборда: чужие правки не затираются. Чат переживает перезагрузку после применения. |
| 10. Тесты | `node --test test/unit.test.js` — unit-тесты чистых функций без Grafana. |

## Сделано в 0.5.3

- Флаг «stream не поддерживается» на сессию браузера: после отказа провайдера stream больше не запрашивается, каждое сообщение — один запрос.
- Лимиты запросов AI: диапазон, таймаут (и для запросов панелей), число запросов за ответ, строки Loki и трейсы Tempo; «Стоп» прерывает запросы к datasource.
- Набор эталонных вопросов `evals/` (16 кейсов) с прогоном через код плагина.
- Сжатие контекста больше не отбрасывает панели после 60-й, пока хватает места для названий (нашлось на кейсе `big-dashboard`).

## Исправлено в 0.5.4

- Фактические жёсткие пределы совпадают с документацией: максимум 200 строк Loki и 20 трейсов Tempo.
- `aiQueryMaxPerTurn` всегда остаётся в безопасном диапазоне 1–20.
- «Стоп» прерывает не только запросы модели, но и начальную загрузку данных панелей.

## Добавлено в 0.6.0

- Выбор панелей перед отправкой: все, ни одной или одна конкретная; данные остальных панелей не запрашиваются и не попадают в контекст.
- Настраиваемая передача контекста: в system prompt или отдельным совместимым документом `grafana-context.json`.
- В UI видны список выбранных панелей и фактический способ передачи последнего запроса.

## Исправлено в 0.6.1

- Автоматический режим использует system prompt и работает с моделями, требующими строгого чередования ролей.
- Расширенный `grafana-context.json` добавляется в текущий user-turn, а не создаёт второе user-сообщение.
- Консервативное окно контекста по умолчанию уменьшено до 8192; рекомендуемый timeout прокси — 300 секунд.

## Исправлено в 0.6.2

- Streaming по умолчанию выключен.
- Снимок всегда отправляется стандартным `image_url`; при ошибке показаны полный ответ API и параметры JPEG без скрытого повтора без изображения.
- «Расследовать» по умолчанию анализирует уже полученные данные. Дополнительные datasource-запросы включаются явной галкой.
- Ошибки 502/504 содержат подсказку про доступность API из pod Grafana и `GF_DATAPROXY_TIMEOUT=300`.

## Добавлено в 0.6.3

- В Configuration можно проверить пять JSON-схем передачи JPEG на уже сохранённой кастомной модели.
- Тестовое изображение создаётся в браузере и содержит проверочный код `VISION-742`; дополнительная инфраструктура не нужна.
- Для рабочего снимка сохраняется формат, который успешно прошёл тест.

## Исправлено в 0.6.4

- Длинный Markdown, таблицы, URL и блоки кода больше не расширяют drawer за пределы viewport.
- Кнопка закрытия закреплена в пределах панели и остаётся доступной после ответа модели.

## Исправлено в 0.6.5

- Свой путь к модели: в настройках виден итоговый адрес чата и списка моделей.
- Повтор версии между API URL и путём (`.../llm/v1` + `/v1/chat/completions` → `/v1/v1/`) убирается при сохранении.

## Осталось

- Предпросмотр отправляемого контекста **до** отправки (сейчас «Последний отправленный контекст» и счётчик токенов после).
- Серверное ограничение роли: `reqRole` маршрутов статичен (Viewer), «минимальная роль» проверяется только в браузере.
- Построчный diff выражений вместо JSON-против-JSON; «Открыть в редакторе панели» без сохранения.
- Сборка на TypeScript (`create-plugin`), если UI будет расти дальше.
- CI с unit-тестами и e2e на имитации Grafana.
- Проверить на стенде дашборды schema v2.

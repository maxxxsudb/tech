# Улучшения Tech AI Assistant

Полный разбор версии 0.4.0 с обоснованием: [review-0.4.0.md](review-0.4.0.md).

## Сделано в 0.5.0

| Пункт разбора | Что сделано |
|---|---|
| 1. Drawer не помнил диалог | Кнопка AI монтирует тот же React-чат, что sidebar и модалка панели. История в `sessionStorage` по дашборду/панели, кнопка «Новый диалог», Esc закрывает drawer. Удалено ~180 строк дублирующего DOM-кода. |
| 2. Markdown и код | Ответы рендерятся через `renderMarkdown` Grafana (с санитизацией). У блоков кода кнопки «Копировать» и «Открыть в Explore» для PromQL/LogQL/TraceQL. |
| 3. Стриминг | `stream: true` через `fetch` к plugin proxy, разбор SSE, кнопка «Стоп» (частичный ответ сохраняется), `<think>` и `reasoning_content` сворачиваются. Если провайдер ответил обычным JSON, он тоже принимается. |
| 4. Контекст | Переменные подставляются через `interpolateVariablesInQueries` datasource (запасной вариант `templateSrv.replace`), значения переменных берутся из состояния дашборда, время по умолчанию из дашборда, панели свёрнутых rows видны и применяются. |
| 5. Бюджет контекста | Настройка «Окно контекста модели». Контекст сжимается по приоритетам без разрезания JSON, старые сообщения истории отбрасываются парами, под полем ввода видно «≈N ток. из M» и что сжато. |
| 6. Провайдеры | Шаблоны Ollama / LM Studio / vLLM / llama.cpp / OpenAI / Gemini / Groq, «Проверить подключение», «Загрузить список моделей» (`/v1/models`, новые маршруты `models`, `models-auth`, `groq-models`). |
| 7. Запросы AI без tools | По умолчанию текстовый протокол `grafana-query`, работающий с любой моделью. Режимы «native tools» и «native с откатом на текст». Последний раунд всегда даёт итоговый ответ. Выполненные запросы видны карточками со ссылкой в Explore. Галка «Разрешить AI выполнять запросы» для обычных вопросов. Типы datasource настраиваются. |
| 8. Применение | `overwrite: false` с версией дашборда: чужие правки не затираются. Чат переживает перезагрузку после применения. |
| 10. Тесты | `node --test test/unit.test.js` — unit-тесты чистых функций без Grafana. |

## Сделано в 0.5.3

- Флаг «stream не поддерживается» на сессию браузера: после отказа провайдера stream больше не запрашивается, каждое сообщение — один запрос.
- Лимиты запросов AI: диапазон, таймаут (и для запросов панелей), число запросов за ответ, строки Loki и трейсы Tempo; «Стоп» прерывает запросы к datasource.
- Набор эталонных вопросов `evals/` (16 кейсов) с прогоном через код плагина.
- Сжатие контекста больше не отбрасывает панели после 60-й, пока хватает места для названий (нашлось на кейсе `big-dashboard`).

## Исправлено в 0.5.4

- Фактические жёсткие пределы совпадают с документацией: максимум 200 строк Loki и 20 трейсов Tempo.
- `aiQueryMaxPerTurn` всегда остаётся в безопасном диапазоне 1–20.
- «Стоп» прерывает не только запросы модели, но и начальную загрузку данных панелей.

## Добавлено в 0.6.0

- Выбор панелей перед отправкой: все, ни одной или одна конкретная; данные остальных панелей не запрашиваются и не попадают в контекст.
- Настраиваемая передача контекста: в system prompt или отдельным совместимым документом `grafana-context.json`.
- В UI видны список выбранных панелей и фактический способ передачи последнего запроса.

## Исправлено в 0.6.1

- Автоматический режим использует system prompt и работает с моделями, требующими строгого чередования ролей.
- Расширенный `grafana-context.json` добавляется в текущий user-turn, а не создаёт второе user-сообщение.
- Консервативное окно контекста по умолчанию уменьшено до 8192; рекомендуемый timeout прокси — 300 секунд.

## Исправлено в 0.6.2

- Streaming по умолчанию выключен.
- Снимок всегда отправляется стандартным `image_url`; при ошибке показаны полный ответ API и параметры JPEG без скрытого повтора без изображения.
- «Расследовать» по умолчанию анализирует уже полученные данные. Дополнительные datasource-запросы включаются явной галкой.
- Ошибки 502/504 содержат подсказку про доступность API из pod Grafana и `GF_DATAPROXY_TIMEOUT=300`.

## Добавлено в 0.6.3

- В Configuration можно проверить пять JSON-схем передачи JPEG на уже сохранённой кастомной модели.
- Тестовое изображение создаётся в браузере и содержит проверочный код `VISION-742`; дополнительная инфраструктура не нужна.
- Для рабочего снимка сохраняется формат, который успешно прошёл тест.

## Исправлено в 0.6.4

- Длинный Markdown, таблицы, URL и блоки кода больше не расширяют drawer за пределы viewport.
- Кнопка закрытия закреплена в пределах панели и остаётся доступной после ответа модели.

## Исправлено в 0.6.5

- Свой путь к модели: в настройках виден итоговый адрес чата и списка моделей.
- Повтор версии между API URL и путём (`.../llm/v1` + `/v1/chat/completions` → `/v1/v1/`) убирается при сохранении.

## Добавлено в 0.7.0

- Данные панелей сводкой: по серии min, max, avg, first, last, время пика и последние точки вместо первых (самых старых) строк; логи — самые свежие строки, таблицы — колонками.
- Убран жёсткий лимит в 4 панели, 4 запроса и 4 кадра: лимиты панелей, запросов, серий, последних точек и строк настраиваются; в чате честный счётчик «данные: N из M».
- Снимок данных на диалог и кнопка «Обновить данные»: уточнения не перезапрашивают datasource, начало промпта стабильно.
- Диапазон времени и переменные читаются при каждой отправке, а не при открытии чата.
- После ошибки модели вопрос возвращается в поле, есть «Повторить», вопрос без ответа не уходит в историю модели; сообщения одной роли подряд склеиваются.
- Результаты дополнительных запросов режутся по свободному месту в окне модели.
- Фактические токены из `usage` и время ответа в строке статистики.
- Настройка «Разрешить снимок дашборда»: если выключена, галки в чате нет.
- «Исправить запрос» и «Оптимизировать» просят выбрать одну панель, если выбрано несколько; блоки `grafana-query` скрыты во время ответа.

## Исправлено в 0.7.1

- Обычный чат больше не перезапрашивает все панели. «Объяснить» получает настраиваемый короткий пример: по умолчанию 3 строки/точки, до 3 панелей, один запрос на панель и последний час.
- «Расследовать» открывает отдельный диалог с диапазоном, лимитами панелей и запросов, общим таймаутом и предварительной оценкой нагрузки.
- Во время сбора отображается `Получаем данные: N из M`; общий таймаут не позволяет недоступным datasource задержать запуск на несколько последовательных таймаутов.
- В статистике показаны запрошенный диапазон данных и суммарный usage всех раундов модели.
- Browser-тест проверяет, что drawer и кнопка закрытия остаются в пределах viewport.

## Добавлено в 0.7.2

- Предпросмотр панелей, диапазона, плана данных, снимка, JSON-контекста и приблизительных токенов перед отправкой.
- Копирование полного ответа и обезличенной диагностики; identity добавляется только явной галкой.
- Более консервативная оценка окна модели: 2 символа на токен.
- Сбор данных нельзя включить в расследовании, если администратор глобально его отключил.
- Профили настроек «Безопасный», «Обычный» и «Глубокое расследование» без изменения подключения и API key.

## Исправлено в 0.7.3

- «Объяснить» снова видит всплески: короткий пример ограничивает строки в сводке, а не `maxDataPoints` запроса (раньше 3 точки на час).
- Профили настроек выставляют полный набор лимитов: «Обычный» после «Глубокого расследования» больше не оставляет глубокие лимиты.
- После «Обновить данные», смены диапазона, переменных или панелей обычные вопросы снова получают данные: снимок помечается устаревшим и перезапрашивается по тому же плану.
- Повторный Enter или повторный клик по тому же действию отправляет запрос после предпросмотра. Новая настройка «Предпросмотр перед отправкой»: всегда, только когда собираются данные или скриншот, никогда.
- Оценка токенов калибруется по реальному `usage.prompt_tokens` модели (в пределах 1,5–4 символа на токен, хранится в браузере для каждого подключения). Без `usage` остаётся 2 символа на токен.
- Новая ступень сжатия «список панелей одной строкой» для больших дашбордов на окне 8k.

## Исправлено в 0.7.4

- Нижний блок действий, снимка, выбора панелей и диагностики сворачивается; поле вопроса остаётся доступным.
- Быстрые действия занимают одну строку с горизонтальной прокруткой.
- История ответа и раскрытый блок контекста прокручиваются независимо и не вытесняют друг друга.

## Исправлено в 0.7.5

- Длинный ответ снова прокручивается целиком. Карточка ответа сжималась под высоту истории (у неё `overflow: hidden`, поэтому flex разрешал ей уменьшаться) и обрезала текст без полосы прокрутки. Сообщения истории больше не сжимаются.
- Заголовки Markdown в ответе уменьшены, чтобы обзор не занимал экран одним заголовком.
- Параметры расследования, предпросмотр отправки, ошибка и «Последний отправленный контекст» прокручиваются в своей области. Раньше при открытом блоке «Действия и контекст» диалог расследования выталкивал поле ввода и кнопку «Отправить» за нижний край drawer (проверено на 1366×768 и 1280×650).

## Исправлено в 0.7.6

- Окно ассистента разделено на вкладки «Чат», «Контекст» и «Диагностика» вместо одного длинного свёрнутого блока. Быстрые действия и поле ввода видны на любой вкладке.
- Подтверждение отправки стоит прямо над полем ввода с одной выделенной кнопкой «Отправить»; полный JSON открывается ссылкой «Что уйдёт в модель» на вкладке «Контекст». Раньше предпросмотр появлялся над историей, и кнопку отправки было легко не заметить.
- Выбор панелей сохраняется для дашборда в `sessionStorage` и не сбрасывается, когда Grafana пересоздаёт drawer при переходах.
- Параметры расследования занимают место истории, а не наезжают на неё.

## Исправлено в 0.7.7

- Быстрые действия и «Новый диалог» убраны в сворачиваемый блок «Действия»; поле ввода остаётся доступным.
- «Расследовать» и ошибки выбора панели автоматически возвращают пользователя на вкладку «Чат».
- Критичные браузерные тесты допускают до 60 секунд на холодный старт Chromium и загрузку Grafana.
- ZIP пересобирается из актуальных исходников и сверяется перед публикацией.

## Исправлено в 0.8.2

- Общий выключатель `imageToTextEnabled` в Configuration для всех пользователей организации. По умолчанию распознавание запрещено; галка «в текст» скрыта. Запрет применяется и при повторе запроса со старыми вложениями.
- «Новый диалог» прерывает старый запрос и немедленно освобождает поле ввода. Поздние ответы, ошибки, прогресс и cleanup предыдущего запроса не меняют новый диалог.
- OCR использует общий Max output tokens (0 — лимит провайдера), а не жёсткие 1024. Обрезанный ответ не отправляется как полная расшифровка.
- Usage учитывает распознавание всех изображений и все раунды основного ответа. Число запросов распознавания показано отдельно.
- Регрессии покрыты `test/assistant-state.test.js`, без запуска контейнеров и обращения к внешней модели.

## Исправлено в 0.8.1

- Выключатель «Разрешить вложения файлов» в Configuration (по образцу снимка): если выключен, в чате нет кнопки «Файл», вставка и перетаскивание файлов игнорируются, уже добавленные файлы не уходят в модель. Профиль «Безопасный» выключает вложения.
- Любой небинарный файл читается как текст (CSV, YAML, XML, SQL, конфиги и т. п.); PDF, DOCX и архивы отклоняются до чтения с понятной подсказкой.
- У изображения в поле сообщения галка «в текст»: модель сначала распознаёт текст и содержимое картинки отдельным запросом, в основной вопрос уходит только текст. У текстовых файлов показано «текстом».
- Предпросмотр пишет, как уйдёт каждое вложение, и предупреждает про изображения только если они действительно отправляются картинкой.
- Блок «Действия» сворачивается на время подтверждения отправки, чтобы история не сжималась до пары строк, и после отправки открывается снова. «Новый диалог» вернулся в шапку.

## Осталось

- Серверное ограничение роли: `reqRole` маршрутов статичен (Viewer), «минимальная роль» проверяется только в браузере.
- Построчный diff выражений вместо JSON-против-JSON; «Открыть в редакторе панели» без сохранения.
- Сборка на TypeScript (`create-plugin`), если UI будет расти дальше.
- CI с unit-тестами и e2e на имитации Grafana.
- Проверить на стенде дашборды schema v2.

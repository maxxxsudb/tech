## Производительность и границы

Медиана пяти холодных загрузок в локальном Node VM: исходники примерно 5–7 мс, финальная защищённая сборка примерно 95–106 мс. Затраты выросли примерно на 0.1 с и проходят установленный абсолютный бюджет 500 мс. Это замер разбора/инициализации модулей, не универсальная оценка браузерного startup и не latency LLM. Точный бюджет ввода/рендера под нагрузкой заказчика не измерялся.

Не включены замораживание DevTools, антиотладочные таймеры, dead-code injection и непроверенная VM-виртуализация. Гарантированный срок реверс-инжиниринга не заявляется.

Временные тестовые контейнеры удалены; новые Docker-образы не скачивались, основная Grafana остановлена. Сборочные npm-зависимости оставлены для повторной локальной сборки. Изменение видимости GitHub и push не выполнялись.

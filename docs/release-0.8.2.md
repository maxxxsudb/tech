# 0.8.2

2026-10-09. Изменения поверх ветки Claude `ed0cdf1` (0.8.1); рабочая ветка `codex/image-to-text-setting`.

- `jsonData.imageToTextEnabled`, по умолчанию false. Выключает распознавание для всех пользователей организации, скрывает галку и применяется к старым вложениям и повтору запроса. Обычная отправка картинок и снимков остаётся доступной.
- «Новый диалог» не получает старые ответы, ошибки или прогресс. Старый cleanup не снимает busy у нового запроса; очистка во время OCR не запускает основной запрос.
- OCR использует общий Max output tokens; 0 не задаёт лимит в payload. При finish_reason=length/max_tokens анализ неполного текста не начинается, показано объяснение.
- Usage суммируется по OCR всех файлов и основным раундам. Расход на распознавание и число его запросов показаны отдельно.
- Исправлена гонка запуска тестов до готовности Grafana: runner ждёт `/api/health`.

Проверки: 49 unit-тестов основного модуля, 13 вложений, 6 диалога/diff и 7 обработчиков Assistant. ZIP проверяется по SHA-256 каждого из 6 файлов.

Контейнеры/образы не создаются, настройки внешней модели браузерный тест не меняет. При тестировании кратко используется существующая Grafana 13.0.2; её исходное выключенное состояние восстанавливается.

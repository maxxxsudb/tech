# 0.9.2 — контекст и черновик без дополнительных постоянных блоков

2026-10-14. База 0.9.1 сохранена: адаптивный период пика, исправленная шапка кода и живой Loki не переделывались.

- Смена панелей/периода/переменных кратко подсвечивает существующую строку контекста. По нажатию открывается popover с предыдущими/новыми значениями и необязательным началом нового диалога. История автоматически не очищается. Наблюдение за URL/переменными не выполняет сетевых запросов.
- Выбор одной панели прямо в чате: действие с несколькими выбранными панелями открывает выбор, а не ошибку. После выбора возвращается к исходному действию с обычным предпросмотром. У Popup есть поиск, закрытие/Esc и восстановление фокуса; это overlay, не дополнительная строка чата.
- Состав отправки раскрывается в существующей подписи под вопросом: фактические панели, период, время получения данных, лимиты, ошибки, пустые результаты и сокращение контекста. Запись фиксируется на момент отправки и не меняется при последующей смене периода. По умолчанию подробности свёрнуты.
- Во время ответа можно писать следующий вопрос. Автоотправки/очереди нет. Завершение ответа не очищает новый черновик или его ручную высоту; быстрые действия не стирают несвязанный текст. Ошибка возвращает исходный вопрос только если не написан новый черновик.
- Понятные имена: «Без данных», «Полученные данные», «Снимок экрана». Значения настроек/provisioning и механика режимов не меняются.

Лимиты панелей, streaming=false и preview=always сохранены. Единый drawer вместо модалки, переделка расследования и два провайдера отложены.

## Проверки

138/138 unit-тестов проходят, в том числе штатный изолированный раннер Node. Все 15 браузерных сценариев прошли на финальном коде Grafana 13.0.2: первые 12 в полном прогоне и последние 3 после актуализации старого ожидания подписи и стабилизации открытия Extensions настоящим наведением/кликом. Код плагина между этими прогонами не менялся.

Новый `verify-092.js` проверяет реальные обработчики UI с контролируемыми ответами модели/datasource: выбор панели без ошибки и скрытого запроса, продолжение исходного действия, сохранение несвязанного черновика, счётчик/причины ограничений, неизменность состава старой отправки, смену периода/переменных без дополнительных запросов ассистента или потери площади истории, ввод при медленном ответе, popover/Esc на desktop и 360 px. Прежние сценарии проверяют light/dark, ручную прокрутку streaming, конфигурацию, модалку, Explore, Canvas и расследование. Живой Loki проверен через настоящий Grafana proxy; модель заказчика не проверялась.

Ожидание окончания ответа в браузерных тестах теперь использует явный `data-busy`, а не disabled textarea: ввод во время ответа намеренно больше не блокируется. Проверка ручной прокрутки ждёт переполнение минимум 96 px, чтобы прокрутка действительно выходила за существующий порог автоследования 48 px; сам порог и поведение автоследования не менялись.

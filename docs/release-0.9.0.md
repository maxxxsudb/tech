# 0.9.0 — прицельный анализ без скрытых запросов

2026-10-14. База — наш интерфейс и механика отправки; присланный вариант не установлен целиком.

## Что вошло

- Компактный composer и Configuration из наработок 0.8.8, явные режимы данных, поиск панелей, сохранение ручной высоты, свёрнутые завершённые шаги. Нативная модалка ограничена размером экрана.
- Explore queries/datasource/range из URL, поддержка реального extension context выбранной панели. Изменение targets/datasource инвалидирует ключ кеша. Для разных периодов Explore нужно выбрать одну вкладку.
- `peakAtMs` в сводке модели; «Проверить пик» открывает отдельное подтверждение с окном ±2 минуты. Дополнительный `aroundTime` ограничен подтверждённым периодом.
- Разведка метрик/labels Prometheus/Loki: отдельное разрешение, известный datasource UID, allowlist, период, отмена/таймаут, ограниченный результат. Текстовый протокол и native tools используют общий счётчик запросов.
- Чтение аннотаций и диффа предыдущей версии — только по выбору пользователя в расследовании. Общий бюджет времени сбора включает события; ошибки доступны в отправленном контексте. «Обновить со следующим вопросом» очищает и кеш событий.
- Запись аннотации — редактируемый текст и время UTC, отдельное подтверждаемое сохранение. Ошибка прав Grafana показывается пользователю. Поздний ответ не восстанавливает закрытый диалог.
- Ручная проверка отмеченных targets: исторический/текущий период дашборда, не более настроенного числа targets и 10 секунд. Отсутствующая панель/новый datasource блокируются. Проверка ничего не сохраняет и не вызывает модель автоматически.
- Опциональный Canvas-снимок только выбранных видимых графиков: исходные координаты и пропорции, отчёт покрытия пользователю и модели, без fallback на чужие панели. Полный захват вкладки остаётся дефолтом; формат передачи изображения не изменён.

## Сохранённые ограничения

Streaming по умолчанию выключен, предпросмотр — `always`. Лимиты панелей не увеличены. SQL-разведка, автоматическая валидация/самоисправление и недостоверная привязка exemplars ко всем рядам не перенесены. Отдельные backend/browser контейнеры и новые базовые образы не нужны.

## Проверки

- 127/127 unit-тестов, в том числе новые проверки периода пика, разрешений и бюджета схемы, таймаутов/отмены метаданных, проверки только выбранных targets, Explore, кеша, событий, аннотаций и запрета захвата чужого Canvas.
- Штатный изолированный раннер `node --test test/*.test.js` также проходит.
- 13/13 браузерных сценариев прошли единым прогоном на единственной существующей Grafana 13.0.2 через `scripts/test-grafana.ps1`, включая новые `verify-088.js` и `verify-090.js`. Проверены реальные обработчики UI, ручная валидация без автоматической проверки, подтверждение и узкий период пика, opt-in событий/схемы, tool rounds, сохранение только явного черновика аннотации, покрытие Canvas и контекст Explore.
- В новых сценариях модель, метаданные и данные datasource контролируются фикстурами; используется настоящий интерфейс Grafana. Другие сценарии работают с локальными Loki/Infinity. Модель заказчика и его инфраструктура не проверялись.

Архив формируется `scripts/package.ps1`: версия manifest/module должна совпасть, содержимое каждого ZIP-entry сверяется по SHA256 с исходным файлом.

После прогона тестовые Grafana, Loki и mock API остановлены. Новые контейнеры и Docker-образы не создавались и не скачивались.

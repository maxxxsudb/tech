# Живая проверка разведки Prometheus — 2026-10-14

Grafana 13.0.2, Prometheus 3.5.0, реальный Node.js-экспортер памяти и uptime внутри существующего контейнера Grafana. Prometheus опрашивает `/metrics` каждую секунду; TSDB хранится в tmpfs до 64 МБ. Нового образа экспортера и второй Grafana нет.

Проверка проходит через интерфейс расследования с явным разрешением разведки, затем через настоящий Grafana datasource proxy. Только ответы LLM — сценарная заглушка; метрики, HTTP API и данные не подменены.

Результат: **PASS**, три последовательных запуска; второй и третий проверяют точные значения, третий также проверяет полный скрипт развёртывания и очистки:

- Поиск `tech_exporter_memory` возвращает `tech_exporter_memory_bytes`.
- Labels включают `environment`, `kind`, `job`, `instance`, `__name__`.
- Значения `kind`: `free`, `total`.
- 105 метрик `tech_exporter_probe_*`: передаются 100, `total=105`, `truncated=true`.
- Несуществующая метрика возвращает пустой успешный результат, не ошибку.
- Точка в строке поиска экранирована как литерал и не совпадает с произвольным символом.
- Все шесть запросов имеют HTTP 200; результаты инструментов доходят до следующего раунда модели.
- Открытие ассистента не запускает разведку автоматически.

Также проходят **138/138 unit-тестов**. Изменения production-кода не потребовались, ZIP 0.9.2 остаётся актуальным.

## Границы проверки

Подтверждён маршрут `/api/datasources/proxy/uid/{uid}/api/v1/...`, используемый плагином. Фактическая модель заказчика, её выбор инструментов, авторизация и его reverse proxy здесь не проверялись. `label_values` получает полный ответ Prometheus и обрезает его уже в плагине: 100 — лимит передаваемых имён, не лимит серверного ответа. На высококардинальных labels это может быть тяжёлым запросом; действует таймаут до 10 секунд.

Сбор настроен по [официальной документации Prometheus](https://prometheus.io/docs/prometheus/latest/getting_started/).

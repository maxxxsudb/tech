# 0.9.4 — корректная упаковка для штатной установки Grafana

2026-10-15. Поведение UI/моделей сохранено из 0.9.3; исправлена упаковка, версия повышена, чтобы не менять уже выданный архив незаметно.

Все файлы ZIP теперь находятся в `tech-ai-assistant-app/`, как требует формат Grafana. Раньше файлы лежали в корне архива. На настоящей Grafana 13.2.2 воспроизведено падение при `GF_PLUGINS_PREINSTALL_SYNC` со старым ZIP: `archive member "attachments.js" tries to write outside of plugin directory`.

Исправлен `scripts/package.ps1`: обязательный prefix plugin ID, проверка безопасных путей и вложенного `plugin.json`, сверка всех шести файлов с исходниками. Добавлены два независимых Node-теста структуры ZIP и побайтового совпадения его содержимого. **145/145 unit-тестов проходят**.

Новый ZIP установлен настоящим встроенным установщиком Grafana 13.2.2 через локальный HTTP-сервер в Docker-сети `internal=true`, без доступа в интернет. Для внутреннего HTTPS воспроизведена ошибка неизвестного CA и проверена успешная установка через монтирование CA + `SSL_CERT_DIR`, без отключения TLS-проверки. Подробности: [install-offline-ca.md](install-offline-ca.md).

Полный запуск с HTTPS-предустановкой также прошёл: `/api/health` — `database=ok`, версия Grafana 13.2.2; `grafana cli plugins ls` показывает 0.9.4; плагин зарегистрирован, `module.js` обслуживается HTTP, SHA-256 всех шести установленных файлов совпадает с исходниками.

Архив: `output/tech-ai-assistant-app-0.9.4.zip`.

SHA256: `49343365E9C30D7F57E2857535C264C29D06099C921E73AB60E26CE21DFD8B55`.

Не извлекайте 0.9.4 в уже созданную папку `tech-ai-assistant-app`: извлекать нужно в общий каталог plugins, иначе получится двойная вложенность. Старые ZIP оставлены для истории, не подменены.

После проверки временные Grafana, ZIP-сервер, изолированная сеть и тестовый сертификат удалены. Новые образы не скачивались. Основной стенд Grafana остаётся выключенным.

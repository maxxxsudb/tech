# 0.9.1 — мобильная шапка кода и окно пика

2026-10-14.

- В шапке кода язык, кнопка копирования и ссылка Explore не переносятся по буквам. При нехватке места переносятся целые элементы.
- Исходный шаг ряда сохраняется до прореживания мини-графика. Окно пика использует не менее двух шагов до пика и одного после; учитывает числовой lookback PromQL/LogQL (`[5m]` и составные длительности). Для старых снимков без шага используется 3 минуты до/1 минута после. Неизвестные макросы lookback не угадываются.
- В диалоге расследования появились редактируемые минуты до/после пика. Период пересчитывается в оценке запросов, обрезается по текущему диапазону и лимиту `aiQueryMaxRangeHours`, проверяется повторно при запуске. Пустое/отрицательное окно блокирует запуск. Настройки лимитов не менялись.
- Живые read-only проверки Loki выявили корректный ответ `{"status":"success"}` без `data` при пустом наборе labels/values. Теперь он трактуется как пустой список, а не ошибка схемы. Ошибочные ответы по-прежнему отвергаются.
- Через настоящий Grafana proxy проверены `/loki/api/v1/labels` и `/loki/api/v1/label/service_name/values`: HTTP 200, результаты инструментов получены. Новые маршруты/fallback не добавлялись. На стенде в выбранном периоде метаданные пусты; это проверяет реальный транспорт и пустой ответ, не нагрузку на большой каталог.

Prometheus не разворачивался и вживую не проверялся: образ отсутствует, новые образы не скачивались. Локальная фильтрация `label_values` сохранена; она не уменьшает размер ответа datasource. Период и таймаут по-прежнему ограничены.

Проверки: 132/132 unit-теста проходят, в том числе в штатной изоляции Node. Полный прогон 14/14 браузерных сценариев прошёл, включая живой Loki, шапку кода на 360 px, изменение окна перед отправкой и регрессию composer/config/modal. После прогона тестовые Grafana, Loki и mock API остановлены.

Тесты используют существующие Grafana 13.0.2 и Loki 3.6.0. Для live-теста подменяется только модель; метаданные и Grafana proxy настоящие. Модель заказчика не проверялась.

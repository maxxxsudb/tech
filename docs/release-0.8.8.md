# 0.8.8: единый интерфейс ассистента

2026-10-14. Наработки включены в 0.9.0; отдельный ZIP 0.8.8 не публиковался. Контракт LLM, streaming по умолчанию и лимиты не меняются.

- Единый composer: файл, снимок, режим данных, отправка. Ручная высота сохраняется при вводе в пределах 42–160 px.
- Явные режимы: авто, только структура, готовый снимок без запросов, пример, расследование. Устаревший снимок не запрашивается заново в режиме «Готовый снимок».
- Снимок снимается для одного вопроса; повтор ошибки переиспользует изображение только для прежнего контекста и при сохранённом согласии. Картинка не записывается в историю.
- Поиск панелей по названию/#id/группе, число доступных запросов. Фильтр не меняет выбор.
- Краткий состав отправки под вопросом; завершённые шаги расследования сгруппированы, ошибки отмечены в summary. Diff предложенных изменений открыт сразу.
- Responsive-сетки ориентируются на ширину контейнера. Configuration имеет стили ассистента и липкое сохранение с индикацией изменений.
- Предпросмотр и ограничения высоты подвала сохранены. Обновление данных явно отложено до следующего вопроса.

Проверки на текущем этапе:

- 108/108 unit-тестов: добавлены проверки явного режима структуры, готового/устаревшего снимка, фильтра без изменения выбора, параметров расследования для своего вопроса, повторного изображения и его выключения, ручной высоты и свёрнутых шагов.
- Новый сценарий `verify-088.js` подтвердил режимы/поиск/повтор снимка/размеры desktop/narrow/mobile, Configuration с сохранением, полную страницу и нативную модалку. Модалка адаптирована к высоте экрана, селектор Extensions исправлен.
- `verify-ux.js` после корректировки отступов сохраняет контроль ≥45% высоты истории на малых экранах, не меняя порог теста. Проверены draft, fullscreen, ручная прокрутка streaming, light/dark.
- A/B 0.8.7→0.8.8: история выросла с 296 до 316 px при 1280×650 и с 386 до 406 px при 360×740. Браузерные регрессии вошли в успешный полный прогон 0.9.0. Ответы модели и захват картинки в новом сценарии подменены; реальная модель заказчика не проверялась.

Не взяты ранние варианты: `previewBeforeSend=data` как новый дефолт, трёхпозиционное расширение, снятие ограничения высоты footer и вывод всех сценариев сразу. Предложения внедрены точечно, без замены всего `module.js` шаблоном.
